# Bank Management System

A Java Swing based desktop application for basic banking operations.

## Features
- User Login
- Create Bank Account
- Deposit Money
- Withdraw Money
- Check Balance
- Transaction History
- Logout

## Technologies Used
- Java
- Java Swing
- Eclipse IDE
- Git & GitHub

## Project Structure
- Login.java
- Dashboard.java
- BankAccount.java
- CreateAccount.java
